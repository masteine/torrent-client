# Простий торрент-клієнт

Невеликий застосунок для завантаження файлів через BitTorrent. У вікні можна відкрити `.torrent` файл або вставити magnet-посилання, вибрати папку, стежити за прогресом, поставити завантаження на паузу та обмежити швидкість. Є також версія для командного рядка.

Зараз застосунок працює з **одним завантаженням одночасно**. Кнопка «Видалити зі списку» зупиняє його, але не видаляє вже завантажені файли. Для роботи потрібне підключення до інтернету. BitTorrent реалізовано за допомогою [`librqbit`](https://github.com/ikatson/rqbit).

## Встановлення віконної версії

Після виходу першого [GitHub Release](https://github.com/masteine/torrent-client/releases) скопіюйте **одну команду** для своєї системи. Інсталятор завантажить готову збірку останнього релізу; Rust встановлювати не потрібно. Повторний запуск команди оновить застосунок.

### macOS (Apple Silicon або Intel) і Linux (x86_64)

Відкрийте Terminal і виконайте:

```sh
curl -fsSL https://raw.githubusercontent.com/masteine/torrent-client/main/install.sh | sh
```

На macOS застосунок з'явиться в `~/Applications/Simple Torrent.app`. На Linux команда встановить його в `~/.local/bin/simple-torrent-gui` і додасть ярлик до меню програм. Готова збірка Linux створюється на Ubuntu 24.04; на інших дистрибутивах можуть знадобитися системні бібліотеки або збірка з коду.

### Windows (x86_64)

Відкрийте PowerShell і виконайте:

```powershell
irm https://raw.githubusercontent.com/masteine/torrent-client/main/install.ps1 | iex
```

Застосунок з'явиться в меню «Пуск» і встановиться для поточного користувача в `%LOCALAPPDATA%\Programs\SimpleTorrent`.

Збірки поки не мають цифрового підпису, тому macOS або Windows можуть показати попередження під час першого запуску. Завантажуйте їх лише зі сторінки цього репозиторію.

## Як користуватися

1. Запустіть «Простий торрент-клієнт».
2. Оберіть `.torrent` файл або вставте magnet-посилання.
3. Виберіть папку для файлів і натисніть «Завантажити».

Типова папка — `Downloads` у домашній папці. Ліміт швидкості вимірюється в КіБ/с; `0` означає відсутність обмеження. Його можна змінити під час завантаження кнопкою «Застосувати». Кнопки «Пауза» й «Відновити» керують поточним завантаженням.

## Збірка з коду

Потрібен [Rust](https://rustup.rs/) з підтримкою edition 2024. На Linux перед збіркою встановіть бібліотеки, потрібні для `eframe` і `rfd` (для Ubuntu: `libxcb-render0-dev libxcb-shape0-dev libxcb-xfixes0-dev libxkbcommon-dev libssl-dev libgtk-3-dev`).

```sh
cargo run --release --locked --bin simple-torrent-gui
```

Версія для командного рядка:

```sh
cargo run --release --locked --bin simple-torrent -- файл.torrent
cargo run --release --locked --bin simple-torrent -- 'magnet:?xt=urn:btih:...' ./мої-файли
```

Другий аргумент — папка для завантаження. Якщо його немає, файли потрапляють у `./downloads`. Для зупинки натисніть `Ctrl+C`.

## Як опублікувати готові збірки

Після публікації файлів в основній гілці створіть і відправте тег версії:

```sh
git tag v0.1.0
git push origin v0.1.0
```

GitHub Actions збере віконний застосунок для macOS (Apple Silicon та Intel), Linux x86_64 і Windows x86_64 та додасть архіви до нового Release. Перед першим тегом перевірте, що версія в `Cargo.toml` відповідає тегу.
